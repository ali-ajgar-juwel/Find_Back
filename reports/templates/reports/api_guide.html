FindBack REST API

Explore report and category data, search reports, and connect another frontend to this project.

Open browsable API ↗Browse reports endpoint

Endpoints

GET/api/reports/List reports
GET/api/reports/1/Report details
GET/api/categories/List categories
POST/api/reports/Create report · login required
PUT/PATCH/api/reports/1/Edit own report · login required
POST/api/claims/Submit a claim · login required

Search, filters & pagination

Use query parameters to narrow results. The API returns paginated results.

/api/reports/?search=wallet
/api/reports/?report_type=LOST
/api/reports/?status=OPEN
/api/reports/?category=1
/api/reports/?ordering=-created_at
/api/reports/?page=2

Try a request

Paste this in your browser to fetch the first page of reports:

http://127.0.0.1:8000/api/reports/

PowerShell example:

Invoke-RestMethod ` -Uri "http://127.0.0.1:8000/api/reports/"
Authentication

Reading public reports is open. Creating, editing, deleting reports and submitting claims require authentication. Report owners control their own reports.

Cache behavior

The homepage, report listings, and public report/category API GET responses are cached briefly (60 seconds). Successful report or claim changes clear the cache so updated data appears on the next request.
